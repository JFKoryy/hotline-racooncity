Concepto del Juego

Survival Horror Top-Down

Navegador Web (HTML5 Canvas)

Tono

Lento, tenso, atmosferico

Inspiraciones

Resident Evil 2 (narrativa) + Hotline Miami (camara y controles)

Hotline RacoonCity combina la narrativa ambiental y la tension del survival horror clasico con la perspectiva cenital y los controles directos de los juegos top-down. El jugador no es un soldado ni un agente entrenado — es un civil asustado, sin experiencia en armas, buscando refugio en una comisaria que resulta ser tan peligrosa como las calles.

La historia se cuenta a traves de documentos dejados por un misterioso "LSK", quien fue el ultimo en salir con vida y dejo pistas para cualquiera que llegue despues.

Historia / Guion

Contexto

Una epidemia desconocida ha arrasado la ciudad. Las calles estan vacias, los coches abandonados, y los gritos dejaron de escucharse hace horas. La unica opcion es buscar refugio.

El Protagonista

Un civil sin nombre y sin experiencia. No sabe mucho del uso de armas, no tiene entrenamiento. Solo quiere sobrevivir. Llega a la comisaria del distrito buscando seguridad, pero lo que encuentra adentro es el caos.

La Escena (Demo)

Al entrar a la recepcion, el protagonista encuentra el cuerpo del Agente M caido junto al mostrador. Sobre el mueble de recepcion, una carta firmada por "LSK":

"Si alguien lee esto: el Agente M no lo logro. Yo fui tras ellos. Trata de salir por la puerta trasera de la comisaria; imagino que la entrada debe estar llena de ellos. Busca la llave en la oficina del segundo piso. Si llegas ahi, tal vez nos encontremos."

— LSK

Al inspeccionar el cuerpo del Agente M, el protagonista encuentra su arma reglamentaria y un cuchillo de combate. Solo puede cargar uno.

Tras elegir, los sonidos del pasillo confirman lo peor: no esta solo. Tres infectados entran a la recepcion.

Mecanicas de Juego

▶

Movimiento

WASD para moverse. El personaje rota hacia donde apunta el cursor del mouse. Movimiento lento y deliberado para generar tension.

⚔

Sistema de Arma Unica

Solo puedes llevar un arma a la vez. Si encuentras una nueva, decides si cambiarla o conservar la actual. Cada arma tiene ventajas y desventajas.

✪

Combate Probabilistico

El protagonista es un civil sin experiencia. Click derecho para apuntar y seleccionar un objetivo, click izquierdo para disparar. La pistola tiene 40% de acierto (sube a 80% conforme avanza la historia). El cuchillo siempre acierta pero requiere estar cuerpo a cuerpo.

🔎

Interaccion

Tecla E para inspeccionar objetos: cuerpos, documentos, puertas, y elementos del entorno que revelan la historia.

📜

Narrativa Ambiental

Documentos de LSK esparcidos por la comisaria cuentan que paso y guian al jugador. La historia no se "cuenta" — se descubre.

👁

Tension Atmosferica

Movimiento lento, campo de vision limitado, sonidos ambientales. El horror viene de no saber que hay en la siguiente habitacion.

Python

1. calcular_probabilidad_acierto(nivel_experiencia)

Calcula la probabilidad de que un disparo acierte segun el progreso del jugador.

def calcular_probabilidad_acierto(nivel_experiencia):
    """
    Calcula la probabilidad de acierto basada en la experiencia.
    Nivel 1 = 40%, incrementa hasta 80% en nivel 10.
    """
    base = 0.40
    incremento = 0.04  # 4% por nivel
    maximo = 0.80
    probabilidad = base + (nivel_experiencia - 1) * incremento
    return min(probabilidad, maximo)

# Ejemplo:
print(calcular_probabilidad_acierto(1))   # 0.40 (inicio/demo)
print(calcular_probabilidad_acierto(5))   # 0.56
print(calcular_probabilidad_acierto(10))  # 0.76 -> tope 0.80

2. intentar_disparo(probabilidad)

Simula un disparo y determina si acierta o falla usando random.

import random

def intentar_disparo(probabilidad):
    """
    Simula un disparo. Retorna True si acierta, False si falla.
    Usa random.random() que genera un float entre 0 y 1.
    """
    resultado = random.random()
    acierto = resultado <= probabilidad
    if acierto:
        print(f"[ACIERTO] Resultado: {resultado:.2f} <= {probabilidad}")
    else:
        print(f"[FALLO] Resultado: {resultado:.2f} > {probabilidad}")
    return acierto

# Ejemplo (demo con 40%):
intentar_disparo(0.40)  # ~40% de veces sera True

3. gestionar_inventario(inventario, arma_nueva, arma_actual)

Implementa el sistema de arma unica: solo una a la vez, decide si cambiar.

def gestionar_inventario(inventario, arma_nueva, arma_actual):
    """
    Gestiona el sistema de arma unica.
    Si el jugador no tiene arma, la toma automaticamente.
    Si ya tiene una, retorna las opciones para elegir.
    """
    if arma_actual is None:
        inventario["arma"] = arma_nueva
        return f"Has tomado: {arma_nueva['nombre']}"
    else:
        return {
            "mensaje": "Ya tienes un arma equipada.",
            "actual": arma_actual,
            "nueva": arma_nueva,
            "opciones": ["mantener", "cambiar"]
        }

# Ejemplo:
inventario = {"arma": None}
pistola = {"nombre": "Pistola M19", "tipo": "rango", "prob": 0.40}
cuchillo = {"nombre": "Cuchillo Tactico", "tipo": "melee", "prob": 1.0}

print(gestionar_inventario(inventario, pistola, None))
print(gestionar_inventario(inventario, cuchillo, pistola))

4. cargar_documento(id_documento, documentos_db)

Busca y retorna un documento narrativo (cartas de LSK) desde la base de datos del juego.

def cargar_documento(id_documento, documentos_db):
    """
    Busca un documento por su ID en la base de datos.
    Retorna el contenido si existe, o un mensaje de error.
    Usa dict.get() para acceso seguro.
    """
    documento = documentos_db.get(id_documento)
    if documento:
        return {
            "encontrado": True,
            "autor": documento["autor"],
            "contenido": documento["texto"],
            "pista": documento.get("pista", None)
        }
    return {"encontrado": False, "mensaje": "Documento ilegible..."}

# Ejemplo:
documentos = {
    "nota_recepcion": {
        "autor": "LSK",
        "texto": "El Agente M no lo logro. Yo fui tras ellos...",
        "pista": "Busca la llave en la oficina del segundo piso."
    }
}
print(cargar_documento("nota_recepcion", documentos))

5. calcular_dano(arma, enemigo)

Calcula el dano infligido considerando el tipo de arma y la resistencia del enemigo.

def calcular_dano(arma, enemigo):
    """
    Calcula el dano real aplicado a un enemigo.
    Dano = dano_base del arma - resistencia del enemigo.
    Minimo 1 de dano (siempre hace algo si acierta).
    """
    dano_base = arma["dano"]
    resistencia = enemigo.get("resistencia", 0)
    dano_real = max(1, dano_base - resistencia)
    
    enemigo["hp"] -= dano_real
    eliminado = enemigo["hp"] <= 0
    
    return {
        "dano_infligido": dano_real,
        "hp_restante": max(0, enemigo["hp"]),
        "eliminado": eliminado
    }

# Ejemplo:
pistola = {"nombre": "Pistola", "dano": 35}
zombie = {"nombre": "Zombie", "hp": 100, "resistencia": 5}

print(calcular_dano(pistola, zombie))  # 30 de dano, 70 HP restante

JavaScript

1. moverJugador(jugador, teclas, deltaTime)

Controla el movimiento del personaje con WASD, aplicando velocidad y deltaTime para movimiento consistente.

function moverJugador(jugador, teclas, deltaTime) {
    /**
     * Mueve al jugador segun las teclas presionadas.
     * Usa deltaTime para que la velocidad sea independiente del FPS.
     * Velocidad lenta (120px/s) para generar tension.
     */
    const velocidad = 120; // pixeles por segundo (lento = tension)
    let dx = 0, dy = 0;

    if (teclas['w'] || teclas['W']) dy = -1;
    if (teclas['s'] || teclas['S']) dy = 1;
    if (teclas['a'] || teclas['A']) dx = -1;
    if (teclas['d'] || teclas['D']) dx = 1;

    // Normalizar diagonal para que no sea mas rapido
    if (dx !== 0 && dy !== 0) {
        dx *= 0.707;
        dy *= 0.707;
    }

    jugador.x += dx * velocidad * deltaTime;
    jugador.y += dy * velocidad * deltaTime;

    return { x: jugador.x, y: jugador.y };
}

// En el game loop: moverJugador(player, keys, 0.016); // 60 FPS

2. rotarHaciaCursor(jugador, mouseX, mouseY)

Rota el sprite del jugador para que siempre mire hacia el cursor del mouse (estilo Hotline Miami).

function rotarHaciaCursor(jugador, mouseX, mouseY) {
    /**
     * Calcula el angulo entre el jugador y el cursor.
     * Usa Math.atan2() para obtener el angulo en radianes.
     * El personaje siempre "mira" hacia donde apunta el mouse.
     */
    const dx = mouseX - jugador.x;
    const dy = mouseY - jugador.y;
    const angulo = Math.atan2(dy, dx);
    
    jugador.rotacion = angulo;
    
    return angulo; // En radianes, usado para ctx.rotate() al renderizar
}

3. detectarColision(entidadA, entidadB)

Detecta si dos entidades (jugador-zombie, bala-zombie) estan colisionando usando distancia circular.

function detectarColision(entidadA, entidadB) {
    /**
     * Deteccion de colision circular.
     * Calcula la distancia entre centros y compara con la suma de radios.
     * Mas simple y natural que colision rectangular para personajes.
     */
    const dx = entidadA.x - entidadB.x;
    const dy = entidadA.y - entidadB.y;
    const distancia = Math.sqrt(dx * dx + dy * dy);
    const distanciaMinima = entidadA.radio + entidadB.radio;

    return {
        colisiona: distancia < distanciaMinima,
        distancia: distancia,
        solapamiento: distanciaMinima - distancia
    };
}

4. mostrarDocumento(contenido, callback)

Muestra un documento narrativo (carta de LSK) en pantalla con efecto de maquina de escribir.

function mostrarDocumento(contenido, callback) {
    /**
     * Muestra texto narrativo con efecto typewriter.
     * Pausa el juego mientras se muestra.
     * Llama al callback cuando el jugador cierra el documento.
     */
    const overlay = document.getElementById('documento-overlay');
    const textoEl = document.getElementById('documento-texto');
    let index = 0;

    overlay.style.display = 'flex';
    textoEl.textContent = '';

    const intervalo = setInterval(() => {
        if (index < contenido.length) {
            textoEl.textContent += contenido[index];
            index++;
        } else {
            clearInterval(intervalo);
            // Mostrar "Presiona E para cerrar"
            document.getElementById('cerrar-hint').style.display = 'block';
        }
    }, 40); // 40ms por caracter = efecto typewriter

    // Listener para cerrar
    const cerrar = (e) => {
        if (e.key === 'e' || e.key === 'E') {
            overlay.style.display = 'none';
            document.removeEventListener('keydown', cerrar);
            if (callback) callback();
        }
    };
    document.addEventListener('keydown', cerrar);
}

5. moverZombieHacia(zombie, objetivo, deltaTime)

IA basica del zombie: se mueve lentamente hacia el jugador en linea recta.

function moverZombieHacia(zombie, objetivo, deltaTime) {
    /**
     * IA simple: el zombie camina hacia el objetivo (jugador).
     * Velocidad lenta (50px/s) para dar tiempo de reaccion.
     * Normaliza la direccion para velocidad constante.
     */
    const velocidad = 50; // Lento, como un zombie real
    const dx = objetivo.x - zombie.x;
    const dy = objetivo.y - zombie.y;
    const distancia = Math.sqrt(dx * dx + dy * dy);

    // No moverse si ya esta encima
    if (distancia < 5) return;

    // Normalizar direccion
    const dirX = dx / distancia;
    const dirY = dy / distancia;

    zombie.x += dirX * velocidad * deltaTime;
    zombie.y += dirY * velocidad * deltaTime;

    // Rotacion del zombie (mira al jugador)
    zombie.rotacion = Math.atan2(dy, dx);
}
